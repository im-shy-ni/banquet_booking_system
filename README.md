# Banquet Booking System

An Online Banquet Booking System is a web-based application that allows users to explore, select, and book banquet halls for various events such as weddings, receptions, birthday parties, and corporate functions.

# Features

## User Features
- User Registration & Login
- View Available Banquet Halls
- Search Halls by Name
- View Hall Details (Location, Capacity, Price)
- Book Banquet Hall
- Prevent Past Date Booking
- Prevent Double Booking
- View My Bookings
- Cancel Booking

## Admin Features
- Admin Login
- Dashboard Overview
- Add New Halls
- Edit/Delete Halls
- View All Bookings
- Approve / Reject Bookings
- View Registered Users
- View Contact Messages
